GymSys

Aplicación de escritorio en Java Swing y SQLite para administrar los socios y membresías de un gimnasio. Permite guardar, editar, eliminar, buscar y filtrar socios por plan, e imprimir el listado en PDF. Valida los datos antes de guardarlos, usa consultas parametrizadas con el patrón DAO y protege el borrado con un PIN de recepción. Funciona sin internet.

Java · Swing · SQLite · NetBeans
